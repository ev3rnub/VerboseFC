6. Key Algorithms & Processes
📄 File Processing Pipeline
  1. Discover files (recursive, depth-limited)
  2. Filter system files
  3. Compute hashes (MD5, SHA256)
  4. Extract metadata (size, timestamps)
  5. Categorize file type
  6. Extract text content
  7. Generate preview
  8. Store in database
🔍 Search Query Processing
  1. Parse natural language query
  2. Extract keywords & phrases
  3. Identify operators (AND/OR/NOT)
  4. Detect date/size filters
  5. Build FTS5 query string
  6. Execute search with ranking
  7. Apply metadata filters
  8. Return ranked results
🔄 Incremental Indexing
  1. Get current index state
  2. Scan file system
  3. Compute current file hashes
  4. Compare with stored hashes
  5. Identify new/modified files
  6. Index only changed files
  7. Update index state
  8. Create version snapshot
