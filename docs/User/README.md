# Verbose FC — User Guide

*Step-by-step guides for everyday use. No technical knowledge needed.*

Verbose FC is a program that looks through a folder on your computer, makes a list
of everything inside it, and lets you search that list — by file name, by the words
inside the files, or by things like size and date. It can also find duplicate files
and show you charts about how your disk space is used.

## Good to know before you begin

- **It only looks where you tell it to.** Nothing is scanned until you pick a folder.
- **It remembers its list.** The list of files (the "index") is saved between visits,
  so the next scan is much faster and only looks at files that changed.
- **Nothing is deleted without you confirming.** Duplicate cleanup always asks you
  first, and "Trash" means your normal Recycle Bin / Trash — files can be restored.
- **It runs on your own computer only.** Other people on your network cannot see it.
